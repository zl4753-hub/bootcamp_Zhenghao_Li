# Homework 12 report

The chosen audience is an investment committee deciding which return assumption to use for planning and whether the analysis is ready for further validation.

A concise Markdown report fits this audience because it opens directly in GitHub or an LMS, keeps the decision headline beside each chart, and preserves transparent links to the reproducible notebook and sensitivity table. The notebook is included as a second, more technical format for reviewers who want to inspect the calculations.

- Main deliverable: `final_report.md`
- Reproducible analysis: `../homework12_results-reporting-delivery-design_submission.ipynb`
- Exported figures: `images/`
- Quantified sensitivity: `sensitivity_summary.csv`
